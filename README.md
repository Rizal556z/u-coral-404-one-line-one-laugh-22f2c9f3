# One Line, One Laugh

One funny line of text, written by a pure-stdlib Python program for the make.fun bounty **One Line, One Laugh**.

> My smart fridge just emailed me a grocery list — apparently my kitchen has started judging me in writing.

Run `python3 main.py` — it writes the line (one line, 105 characters, no trailing newline) to `/output/entry.txt` and re-reads it to assert the gate constraints (1–200 characters, single line, no trailing newline).
